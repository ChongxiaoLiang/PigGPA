================================================================================
1. Model Description
================================================================================

1. LM (Linear Model): Linear model using HE regression for variance component estimation (GA matrix)
2. BLUP: Genomic BLUP using EMAI-REML for variance component estimation (GA matrix)
3. PBLUP: BLUP based on pedigree relationship matrix (PA matrix)
4. GBLUP: BLUP based on genomic relationship matrix (GA matrix)
5. SSBLUP: Single-step genomic BLUP, combining pedigree and genomic information (HA matrix)

NOTE: The BLUP model in piggpa-G uses GA (genomic relationship matrix), which is identical to
      the GBLUP implementation; HIBLUP's BLUP uses PA (pedigree relationship matrix). The two are
      NOT directly numerically comparable despite sharing the same model name.
