附图标题：Claude Code Agent 在猪眼肌深度 GWAS 及调控注释中的完整结果

附图说明（Figure Caption）：

附图 X | 通用 AI Agent (Claude Code) 在猪眼肌深度全基因组关联分析及调控区预测中的独立复现结果

(A) 曼哈顿图（Manhattan plot）带调控注释。X 轴为 18 条常染色体（SSC1–SSC18），Y 轴为 −log₁₀(P)。灰色点为全部 258,074 个通过 QC 的 SNP（HWE P>1e-6, MAF>0.01），橙色点为 Bonferroni 显著 SNP（P < 1.94×10⁻⁷, n = 1,064），蓝色点为 suggestive SNP（P < 1×10⁻⁵, n = 3,913）。水平虚线分别标注 Bonferroni 阈值（红色）和 suggestive 阈值（蓝色）。点颜色深浅编码调控潜力评分（RPS, Regulatory Potential Score）：深色 = 强调控（RPS ≥ 0.60），中色 = 中等调控（0.45 ≤ RPS < 0.60），浅色 = 弱调控（0.30 ≤ RPS < 0.45）。共鉴定 162 个独立位点，其中 50 个强调控、55 个中等调控、37 个弱调控、20 个非调控。

(B) 分位数-分位数图（QQ plot）含 95% 置信区间。X 轴为期望 −log₁₀(P)，Y 轴为观测 −log₁₀(P)。灰色阴影带为 95% CI。基因组膨胀因子 λ = 2.956，严重偏离理想值 1.0，表明存在显著的群体结构或亲缘关系导致的假阳性膨胀。该方法（PLINK --linear 线性回归，含 year/batch/sex 协变量）未使用混合模型或基因组关系矩阵（GRM）校正群体结构，与 PigGPA（GCTA MLMA, λ = 0.989）形成鲜明对比。

(C) 调控潜力评分分布。左图：162 个独立位点的 RPS 分布直方图，虚线标注分类阈值（0.30, 0.45, 0.60）。右图：强调控 vs 非调控位点的 SNP 密度（50 kb 窗口内 SNP 数）比较，调控位点平均 SNP 密度（36 SNP/50 kb）显著高于非调控位点（10 SNP/50 kb），提示调控区变异富集。

(D) Top 15 位点详情。每个位点标注染色体位置、P 值、RPS 评分及调控分类。最强信号位于 SSC4:20.4–22.5 Mb（P = 8.77×10⁻¹⁵, RPS = 0.568），但该位点不在文献报道的主效 QTL（SSC7:30–38 Mb）区域内，反映群体结构未校正导致的假阳性信号错位。

方法学说明：Claude Code 在完全隔离的工作区（bwrap 沙箱, 无记忆/无 skill/无配置）中自主选择 PLINK --linear 进行 GWAS 分析。调控预测采用启发式统计评分（RPS），基于 SNP 密度、MAF、CpG 岛重叠等基因组特征计算，未使用深度学习模型（如 pig-mutbert）。RPS 为自定义经验公式，缺乏机器学习模型的预测能力。

数据来源：2,797 头猪的 PLINK 二进制格式基因型数据（258,662 SNPs），表型为眼肌深度（mm, .fam 第 6 列），协变量包括 year、batch、sex。QC 后保留 258,074 SNPs 和 2,795 个体。

关键结论：尽管 Claude Code 成功完成 GWAS + 调控注释的完整流程，但因未使用混合模型校正群体结构（λ = 2.956），导致 1,064 个 Bonferroni 显著 SNP 中绝大多数为假阳性。调控预测为启发式统计方法，与基于深度学习的 pig-mutbert 相比缺乏生物学预测能力。生物学评分：3/5（GWAS 2 分 + 调控预测 1 分）。
