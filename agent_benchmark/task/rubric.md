# Agent Benchmark Task Rubric: GWAS + Regulatory Activity Prediction (G→P→A)

总分 = GWAS 方法学 (0–3) + 调控活性预测 (0–2) + 可视化产出 (0–3) + 流程完整性 (0–2) = 0–10

## GWAS 方法学段 (0–3 分)

| 分数 | 标准 |
|------|------|
| 3 | 选用混合线性模型（如 GCTA MLMA-LOCO）校正群体结构；产出关联结果 + Manhattan 图 + QQ 图；λ 接近 1.0；显著 SNP 数量合理 |
| 2 | 产出关联结果 + 至少 1 张图，但方法存在缺陷（如未用混合模型、λ 偏离但已报告） |
| 1 | 产出关联结果但无图，或结果明显异常（如 λ 严重偏离、全 NA、0 显著） |
| 0 | 无关联结果 |

检查要点：
- .fam 第 6 列为眼肌深度表型（定量性状），应用线性回归而非 logistic
- 协变量文件 lmd.cov 含 year/batch/sex，理想情况应纳入协变量
- 是否使用 GRM 校正群体结构（GCTA MLMA）vs 简单线性回归（PLINK --linear）
- λ（基因组膨胀因子）应接近 1.0；λ≈2.95 说明存在严重群体分层导致的假阳性

## 调控活性预测段 (0–2 分)

| 分数 | 标准 |
|------|------|
| 2 | 对显著 SNP 所在区域产出功能元件预测结果（如 ATAC/enhancer/promoter 概率值）；预测方法基于猪基因组模型（pig-mutbert 或等效） |
| 1 | 有调控预测的尝试但不完整或方法不当（如用人类模型、未提取序列、仅文字描述无数值输出、启发式评分） |
| 0 | 无调控预测产出 |

检查要点：
- 理想流程：GWAS 显著 SNP → 提取侧翼序列 → pig-mutbert 预测功能元件
- 预测结果应含具体概率值（非仅文字描述）
- 方法应针对猪基因组（Sscrofa11.1），非人类模型迁移
- 启发式评分（如 RPS）或基因重叠注释不算序列级调控活性预测

## 可视化产出段 (0–3 分)

| 分数 | 标准 |
|------|------|
| 3 | 产出 Manhattan 图 + QQ 图 + 调控元件注释轨道图（完整可视化） |
| 2 | 产出 Manhattan 图 + QQ 图，但无调控元件可视化 |
| 1 | 仅产出 1 种图（Manhattan 或 QQ 之一） |
| 0 | 无可视化产出 |

检查要点：
- Manhattan 图应含全基因组 −log10(P) 散点及显著性阈值线
- QQ 图应含观测 vs 期望 P 值对比及 λ 标注
- 调控元件注释图应展示 SNP 侧翼序列的 7 种调控特征预测值

## 流程完整性段 (0–2 分)

| 分数 | 标准 |
|------|------|
| 2 | 完整执行 G→P→A 流程：基因型质控 → GWAS 关联 → 调控活性预测，端到端闭环 |
| 1 | 完成 G→P 部分（GWAS 关联），但调控预测不完整或方法不当 |
| 0 | 仅完成部分步骤，无端到端流程 |

检查要点：
- G（基因型）：质控、GRM 构建、混合模型关联
- P（表型）：表型文件提取、协变量处理
- A（注释）：显著 SNP 侧翼序列提取 → pig-mutbert 调控活性预测
- 是否实现从 GWAS 到调控预测的自动衔接
