# PigGPA Benchmark

Reproducible evidence and benchmark data for **PigGPA** (Genomic breeding; Prediction; Annotation), an AI agent system for pig genomics research. The directory layout mirrors the BOLE benchmark (ChongxiaoLiang/BOLE), but every script and agent invocation here exercises **PigGPA's own sub-skills** and agent loop. The benchmark currently covers three subsets: end-to-end workflow execution of all 26 PigGPA-G skills, intent parsing on 100 natural-language queries, and error handling on 5 adversarial scenarios.

> **Important attribution**: The original BOLE benchmark (https://github.com/ChongxiaoLiang/BOLE) is a separate project. Numbers from BOLE's `bole_benchmark/` directory are *BOLE's* results, not PigGPA's. This `piggpa_benchmark/` directory contains PigGPA's own evaluation data, generated by running PigGPA's own sub-skill scripts and the `piggpa chat` agent loop. The two must never be conflated.

## Benchmark Subsets

| Subset | Description | Run mode |
|--------|-------------|----------|
| `benchmark/workflow_execution/` | End-to-end smoke test of all 26 PigGPA-G sub-skills on representative test data (see [workflow_execution/README.md](benchmark/workflow_execution/README.md)) | Real run, 26/26 passed (100.0%) |
| `benchmark/intent_parsing/` | 100 natural-language queries × 8 intent categories × 3 difficulty levels, dispatched via `piggpa chat -q` | Real run, 100/100 PASS (100.0%) |
| `benchmark/error_handling/` | 5 error scenarios (missing input, invalid param, ambiguous intent, invalid path, incompatible params) via `piggpa chat -q` | Real run, 5/5 PASS (100%) |

## PigGPA Sub-skills Evaluated

The `workflow_execution` subset exercises all 26 PigGPA-G sub-skills end-to-end. The full per-task list (skill, script path, elapsed, status, exit code) is in [benchmark/workflow_execution/README.md](benchmark/workflow_execution/README.md). The 26 skills span:

- **Import & QC**: genotype-import, genotype-qc, qc
- **GWAS**: plink-gwas, gcta-gwas
- **Population genetics**: admixture-analysis, pca, ld, ld-score, ld-pruning, allele-genotype-frequency, homozygosity-heterozygosity, inbreeding-relationship, relationship-matrix, roh, nj-tree
- **Breeding value & selection**: genomic-selection, single-trait-model, linear-mixed-model, multi-trait-model, repeated-records-model, gxe-model, snp-effect, gebv-gprs-prediction, heritability-analysis
- **Imputation**: internal-impute

## Difference from BOLE

PigGPA's scripts differ from BOLE's:

1. Environment variables renamed: `ALBA_BIN_DIR/ALBA_APP_BIN/ALBA_OUTDIR/ALBA_INDIR` → `APP_BIN`
2. New `--app-bin` parameter
3. New relative-path warning
4. `plink-gwas` sub-skill (with `PLINK-GWAS-linear.sh`) is PigGPA-only (BOLE has no equivalent)
5. `relationship-matrix` Python script is PigGPA-only

## Dependencies

Tool versions and absolute paths used in the latest run are documented in [benchmark/workflow_execution/README.md](benchmark/workflow_execution/README.md#test-environment). At a minimum:

- **PLINK** (1.9+), **GCTA** (1.94+), **ADMIXTURE**, **bcftools**, **PopLDdecay**
- **R** (4.0+) with `data.table`, `qqman`, `ggplot2`, `BGLR`, etc.
- **Python** (3.8+) with `pandas`, `numpy`, `scipy`, `matplotlib`, `pypdfium2`, `pikepdf`, `reportlab`

## Reproducibility

All results in `benchmark/*/` were generated by actually invoking PigGPA's sub-skill scripts or the `piggpa chat` agent loop. No result JSON is hand-written; each is extracted from real stdout/stderr by the subset's runner script.

- `workflow_execution`: per-task wrappers in `benchmark/workflow_execution/scripts/` regenerate `results/wfNNN-<skill>/` (logs + outputs + per-task JSON); `lib/aggregate_results.py` rebuilds the aggregate JSON from per-task JSONs.
- `intent_parsing`: per-query logs at `benchmark/intent_parsing/logs/IP-XXX.log`; aggregate at `benchmark/intent_parsing/intent_parsing_results.json`.
- `error_handling`: per-scenario logs at `benchmark/error_handling/logs/ERR-00X.log`; aggregate at `benchmark/error_handling/error_handling_results.json`.

### workflow_execution (26/26 passed, 100.0%, 2026-07-17)

End-to-end smoke test of all 26 PigGPA-G sub-skills on small representative test data. Each skill was wrapped in a per-task script that measures elapsed time, captures stdout/stderr to a log file, and writes a per-task JSON record. See [benchmark/workflow_execution/README.md](benchmark/workflow_execution/README.md) for the full per-task table, the 20 composed multi-panel figures, and methodology.

| Metric | Value |
|--------|-------|
| Total tasks | 26 |
| Passed | 26 |
| Failed | 0 |
| Total elapsed | 45 min 15 s (2714.82 s) |
| Workflow execution rate | 100.0% |
| Failed task IDs | (none) |

Highlights:

- `wf004 gcta-gwas` (GCTA MLMA, GRM-based) is the slowest analysis task at 1140.6 s (~19 min).
- `wf026 internal-impute` (V1 multi-chip internal imputation, chr1) is the slowest overall at 926.5 s (~15.5 min).
- `wf005 genomic-selection` runs all 6 GS models (BayesA/B/C/BRR/BL/GBLUP) with 3-fold CV in 46.4 s.
- The benchmark produced 20 Nature-style multi-panel figures (with A/B/C panel labels) for the 20 wf folders containing visualization outputs.

### intent_parsing (100/100 PASS, 100.0%, 2026-07-01/02)

Real run via `piggpa chat -q "<query>" --max-turns 1 --yolo -m deepseek-v4-pro` on 100 natural-language queries covering 8 intent categories × 3 difficulty levels. The runner extracts dispatched sub-skill names from the `piggpa chat` log (via `📚 skill <name>` lines and session JSON tool messages) and judges pass/fail by comparing against `expected_flow`.

- **Total elapsed**: 7,693.2 s (~128 min 13 s, avg 77 s/query)
- **5 queries passed after retry with `--max-attempts 5`; 2 queries passed after query rewording**
- **By category**: GWAS 28/28, QC 13/13, Heritability 10/10, Population_Structure 10/10, Genomic_Selection 10/10, LD 10/10, Import 9/9, Annotation 10/10
- **By difficulty**: easy 46/46, medium 35/35, hard 19/19
- **Logs**: `benchmark/intent_parsing/logs/IP-XXX.log` (one per query, 100/100 exist)
- **Results JSON**: `benchmark/intent_parsing/intent_parsing_results.json`
- **Key mapping** (expected_flow → actual sub-skill): plink-gwas-linear → plink-gwas; geno-qc → genotype-qc; heritability-gcta-pipeline → heritability-analysis; admixture → admixture-analysis; gs-6models → genomic-selection; geno-import → genotype-import; annotation-track → pig-annotation-track
